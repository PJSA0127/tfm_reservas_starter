# Instrumento independiente de evaluación — v0.1

## 1. Estado

**CERRADO PARA PILOTAJE / PILOTO NO INICIADO / FREEZE DEFINITIVO PENDIENTE.**

## 2. Objetivo

Evaluar después de concluir ambos procesos:

- cobertura de los seis requisitos;
- correspondencia de hallazgos con D01–D05.

El instrumento no se utiliza como guía durante el proceso convencional.

## 3. Responsables

### Aplicación inicial — I2

I2 analiza únicamente evidencia cerrada y aplica los criterios congelados.

### Revisión — I3

I3 comprueba:

- consistencia;
- suficiencia de evidencia;
- aplicación equivalente de criterios;
- ausencia de evidencia retroactiva.

### Revisión final — I1 + I2 + I3

I1 puede aclarar hechos ya registrados, pero no producir nueva evidencia.

La clasificación definitiva se aprueba por consenso.

## 4. Regla de evidencia

Un requisito recibe `1 = verificado` solo si existe:

- actividad orientada al criterio;
- evidencia cerrada;
- resultado observable.

Si la evidencia es insuficiente:

```text
0 = no verificado
```

## 5. Tipos de evidencia admitidos

- resultados funcionales;
- resultados de seguridad;
- evidencia manual;
- revisión de código documentada;
- Semgrep;
- ZAP;
- artifacts CI;
- matriz requisito-prueba-evidencia.
